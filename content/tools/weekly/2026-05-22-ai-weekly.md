# AI 工具周刊 #22 · 2026-05-22

本期聚焦多模态与工作流自动化领域的最新进展。

---

## 本周精选

### 1. OpenUI —— 用自然语言生成前端界面

- **类别**: 前端开发 / 代码生成
- **亮点**: 支持实时预览、组件库联动，可将 UI 截图反编译为可运行代码
- **链接**: https://github.com/wandb/openui

### 2. TaskWeaver —— 微软开源的多智能体任务协作框架

- **类别**: AI Agent / 自动化
- **亮点**: 支持代码解释器 + 插件系统，可将复杂任务自动拆解为子任务
- **链接**: https://github.com/microsoft/TaskWeaver

### 3. RAGFlow —— 深度文档理解的 RAG 引擎

- **类别**: 检索增强生成
- **亮点**: 支持 PDF/Word/Excel/PPT/图片等格式的智能分块与 OCR，企业级 RAG 方案
- **链接**: https://github.com/infiniflow/ragflow

### 4. VideoLingo —— 视频翻译与本地化工具

- **类别**: 音视频 / 翻译
- **亮点**: 自动语音识别 + 翻译 + 字幕生成 + TTS 配音一站式流水线
- **链接**: https://github.com/huanshere/VideoLingo

### 5. Quivr —— 第二大脑知识管理

- **类别**: 个人知识管理
- **亮点**: 接入多种 LLM，支持 URL / 文件 / 文本导入，语义搜索与对话式知识检索
- **链接**: https://github.com/QuivrHQ/quivr

---

## 趋势观察

- 多模态模型在视频理解领域持续突破，VideoLingo 等工具大幅降低视频本地化门槛
- Agent 框架从单一 Agent 向多 Agent 协作演进，TaskWeaver 代表了微软在企业级 Agent 方向的投入
- RAG 技术走向深水区，文档解析精度成为竞争焦点
