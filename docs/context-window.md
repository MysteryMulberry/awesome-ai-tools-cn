# 上下文窗口优化

## 各模型上下文长度
| 模型 | 上下文长度 | 有效长度 |
|------|-----------|----------|
| GPT-4o | 128K | ~64K |
| Claude 3.5 | 200K | ~128K |
| Gemini 1.5 | 1M | ~512K |
| Qwen2.5 | 128K | ~64K |

## 优化策略
### 1. 摘要压缩
对长文档先摘要再输入

### 2. 分块检索(RAG)
将文档分块，按需检索相关片段

### 3. 滑动窗口
保留最近N轮对话+系统提示

### 4. 关键信息提取
提取与任务相关的核心信息

### 5. 级联调用
先粗读筛选，再精读分析

## 记忆管理
- 短期记忆: 当前对话上下文
- 长期记忆: 向量数据库持久化
- 工作记忆: 当前任务中间结果
