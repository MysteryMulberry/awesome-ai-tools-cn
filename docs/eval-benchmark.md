# AI评估与基准测试

## 主流基准
| 基准 | 评估维度 | 顶级得分 |
|------|---------|----------|
| MMLU | 多学科知识 | ~90% |
| HumanEval | 代码生成 | ~90% |
| GSM8K | 数学推理 | ~95% |
| MATH | 高等数学 | ~70% |
| GPQA | 博士级问答 | ~65% |
| IFEval | 指令遵循 | ~85% |

## 中文基准
| 基准 | 说明 |
|------|------|
| C-Eval | 中文多学科 |
| CMMLU | 中文综合 |
| SuperCLUE | 中文综合排行 |

## 实践建议
1. 选择与任务匹配的基准
2. 关注真实场景表现而非刷榜
3. 建立内部评估数据集
4. 定期回归测试防止退化
