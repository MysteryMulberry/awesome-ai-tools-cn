# agent-qa：有记忆的 AI 测试工具

[agent-qa](https://vostride.com) 用自然语言描述用户流程，并在 Web、Android 和 iOS 应用上执行测试。

## 特性

- 持久记忆引擎复用已验证的测试经验。
- 自我改进通过验证后才保留新知识。
- 提供 CLI、仪表板、MCP 服务器和 Agent Skills。

## 使用场景

端到端 UI 测试、回归测试、移动应用验证，以及编程 Agent 的测试工作流。

## 使用前提与链接

需要 Node.js 24+ 和支持的模型服务；移动测试还需要相应设备工具。本地包免费，模型服务费用另计。许可证：FSL-1.1-ALv2。
