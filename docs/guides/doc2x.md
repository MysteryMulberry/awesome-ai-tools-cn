# Doc2X

[国内产品入口](https://doc2x.noedgeai.com/) · [API](https://open.noedgeai.com/) · [官方 MCP 源码与文档](https://github.com/NoEdgeAI/doc2x-mcp)

## 简介

Doc2X 是 NoEdgeAI 的 AI 文档处理工具，面向带公式、表格和复杂版面的文档。

## 特性

- PDF、扫描件和图片解析为 Word、Markdown、LaTeX。
- 识别公式与表格，支持 PDF/Word 文档翻译。
- 提供 Zotero 插件、开发者 API 和 MIT 开源 stdio MCP。

## 场景与费用

适合科研论文阅读、扫描件整理、办公文档转换和开发者解析工作流。网页有免费试用及部分免费工具，其余使用会员/积分；API 需自己的 Key 并按用量计费。MIT 代码开源不代表 API 永久免费。

依据官方公开页面与 README 整理；未声称实测付费 API。
