# MoeRouter

MoeRouter 是面向开发者的多模型 API 网关，可在兼容的客户端里通过一个账号调用 Claude、GPT 和 Gemini 等模型。

## 功能与适用场景

- 在接入前查看模型 ID、可用接口和参考价格。
- 从现有 SDK、Codex 或 Claude Code 切换模型，减少重复配置。
- 网关依据可用线路与价格选择路由，按实际请求以人民币计费。
